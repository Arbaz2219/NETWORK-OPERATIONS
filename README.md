# Jaffer Network Dashboard

Interactive network monitoring frontend demonstration for Jaffer Brothers.

## Technology
- HTML5 for page structure
- CSS3 for styling and responsive layouts
- Vanilla JavaScript for navigation, charts, filters and interactions
- SVG charts generated by JavaScript
- Browser localStorage for demonstration preferences

No framework, package installation, backend or database is required.

## Run
Open index.html in Chrome or Edge. Keep styles.css, app.js and logo.png alongside it.
Alternatively, serve this directory with any static web server.

## Features
Overview, devices and interfaces, WAN quality, VLANs, branches, topology,
endpoint traffic, alerts, CSV reports and browser-local settings.

Site filters, device details and acknowledgment interactions use sample data.
The speed test is simulated. This is not a live monitoring system.

## Files
- index.html: dashboard structure
- styles.css: responsive styles
- app.js: sample data and dashboard behavior
- logo.png: company logo supplied for this project

## Live implementation still required
A collector with network access, read-only SNMP/API integrations, authenticated
backend, metric storage, real notification delivery and production access controls.
Do not place device passwords, API tokens or SNMP credentials in frontend files.

## Validation
The original demo passed 40 section/site rendering combinations and checks for
device details and alert acknowledgment using a minimal DOM harness.
Browser visual verification has not been completed. Those checks are not a
substitute for end-to-end browser tests or production acceptance.
